# خادم واتساب مجاني لإرسال أكواد التحقق (OTP)

الفكرة: بتربط رقم واتساب حقيقي (يفضّل رقم منفصل عن رقمك الشخصي) بهذا الخادم عن طريق مسح كود QR،
والخادم بيفضل شغال ويستقبل طلبات من موقعك ويبعت الأكواد فعليًا على واتساب العملاء — من غير ما تدفع
لأي شركة وسيطة.

⚠️ **مهم قبل ما تبدأ:**
- ده حل غير رسمي (مش من واتساب نفسه)، فيه احتمال (بسيط لكن موجود) إن الرقم يتقيّد لو استخدمته بكثافة عالية جدًا. استخدم رقم منفصل عن رقمك الشخصي إن أمكن.
- الخادم لازم يفضل شغال طول الوقت. لو قفلته أو الجهاز اتقفل، الإرسال هيوقف والموقع هيرجع تلقائيًا لوضع "الكود يظهر على الشاشة".

## 1) المتطلبات
- جهاز يقدر يفضل شغال أغلب الوقت: كمبيوتر إضافي، أو VM مجاني دائم (زي Oracle Cloud Always Free — مجاني للأبد وموثوق أكتر من كمبيوتر شخصي).
- Node.js مثبت على الجهاز (نسخة 18 أو أحدث): https://nodejs.org
- رقم واتساب (يفضل رقم منفصل، شريحة إضافية أو رقم واتساب بيزنس).

## 2) التثبيت والتشغيل محليًا
```bash
cd whatsapp-bridge
npm install
cp .env.example .env
```
افتح ملف `.env` واختار أي كلمة سر طويلة عشوائية في `SHARED_SECRET` (هتحتاجها تاني في الخطوة 4).

```bash
npm start
```
هيظهر كود QR في الشاشة. من موبايلك: افتح واتساب > الإعدادات > الأجهزة المرتبطة > ربط جهاز > امسح الكود.
بعد الربط هتلاقي رسالة "✅ تم ربط واتساب بنجاح!" — الخادم بقى جاهز.

## 3) خلي الخادم متاح على الإنترنت (عشان Supabase يقدر يوصله)
الخادم شغال على جهازك بس لسه مش متاح من بره. أسهل طريقة مجانية: **Cloudflare Tunnel**.

```bash
# ثبّت الأداة (مرة واحدة فقط):
# https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/

cloudflared tunnel --url http://localhost:3000
```
هيديك رابط زي: `https://xxxx-xxxx.trycloudflare.com` — ده الرابط اللي هتستخدمه في الخطوة الجاية.
(ملحوظة: الرابط ده بيتغيّر كل مرة تشغّل فيها الأمر من جديد، إلا لو عملت حساب Cloudflare مجاني وعملت Tunnel دائم بنفس الاسم.)

## 4) اربط الخادم بموقعك (Supabase)
من لوحة تحكم Supabase → Edge Functions → Secrets (أو عن طريق الـ CLI)، ضيف:
```
WHATSAPP_BRIDGE_URL=https://xxxx-xxxx.trycloudflare.com/send-otp
WHATSAPP_BRIDGE_SECRET=نفس الكلمة اللي حطيتها في SHARED_SECRET
```
بعدين انشر (Deploy) دالة `send-otp` المحدّثة من مجلد `supabase/functions/send-otp` في مشروع المتجر.

## 5) لازم يفضل شغال طول الوقت
- سيبه شغال في الخلفية (أو استخدم أداة زي `pm2` عشان يشتغل تلقائيًا لو الجهاز اتقفل وفتح تاني: `npm i -g pm2 && pm2 start server.js`).
- لو استخدمت Oracle Cloud Always Free VM بدل جهازك الشخصي، الخادم هيفضل شغال 24 ساعة بدون ما تسيب جهازك مفتوح، وهتاخد IP ثابت مش محتاج Cloudflare Tunnel أصلاً (تقدر تفتح المنفذ مباشرة).

## استكشاف الأخطاء
- لو الموقع رجع يعرض الكود على الشاشة بدل الإرسال، معناه الخادم مش شغال أو الرابط غلط أو الكلمة السرية مش متطابقة — تأكد من الخطوات 3 و4.
- لو ظهر "whatsapp_not_ready" — لازم تمسح كود QR تاني (الجلسة اتفصلت).
